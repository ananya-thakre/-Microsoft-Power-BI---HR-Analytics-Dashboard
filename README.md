# 📊 HR Analytics Dashboard

![HR Analytics Dashboard image](https://github.com/1-Virus/-Microsoft-Power-BI---HR-Analytics-Dashboard/assets/167788224/ae5c562f-795d-4eae-a129-498983dabef0)

## Overview

The HR Analytics Dashboard is a comprehensive Power BI solution designed to provide actionable insights into human resources metrics and organizational performance. This dashboard enables HR professionals and business leaders to monitor key HR indicators, track employee metrics, and make data-driven decisions! 🚀

## ✨ Features

- **Employee Overview**: Total headcount, active employees, and workforce distribution
- **Attrition Analysis**: Tracks employee turnover by department, tenure, and demographics
- **Performance Metrics**: Monitor key performance indicators (KPIs) related to recruitment and retention
- **Department Breakdown**: Analyze HR metrics by department and team
- **Demographic Insights**: Visualize workforce composition by age, tenure, and other dimensions
- **Trend Analysis**: Historical trends in hiring, attrition, and other key metrics

## 📚 Data Sources

This dashboard connects to HR data sources including:
- Employee records and demographics
- Attrition and termination data
- Department and role information
- Performance and engagement metrics

## 🚀 Getting Started

### Prerequisites

- Microsoft Power BI Desktop (latest version recommended)
- Access to your organization's HR data
- Appropriate data permissions and compliance clearance

### Installation

1. Clone or download this repository
2. Open the Power BI file (.pbix) in Power BI Desktop
3. Connect to your data source
4. Refresh the data to load the latest HR metrics
5. Publish to Power BI Service for team access (optional)

## Dashboard Pages

- **Executive Summary**: High-level overview of key HR metrics
- **Detailed Analytics**: In-depth analysis of attrition, performance, and workforce trends
- **Department Performance**: Department-specific insights and comparisons
- **Employee Details**: Individual employee records and historical data

## 📈 Key Metrics

- **Attrition Rate**: Percentage of employees who left the organization
- **Headcount**: Total number of active employees
- **Recruitment Metrics**: Hiring trends and recruitment effectiveness
- **Tenure Distribution**: Employee tenure across the organization
- **Department Distribution**: Workforce spread across departments

## Usage

1. Use filters and slicers to explore specific departments, time periods, or employee groups
2. Hover over visualizations for detailed tooltips and information
3. Use drill-through features to navigate between dashboard pages for deeper analysis
4. Export reports for presentations and stakeholder communication
